# Οδηγός ΠΕΑ & ΤΕΕ-ΚΕΝΑΚ (Energy Inspection App)

Εξειδικευμένη διαδικτυακή εφαρμογή για Ενεργειακούς Επιθεωρητές & Μηχανικούς στην Ελλάδα, για την προετοιμασία, υπολογισμό, έλεγχο και εξαγωγή αρχείων **XML (v1.31)** για το λογισμικό **ΤΕΕ-ΚΕΝΑΚ**.

---

## 🚀 Δυνατότητες & Εργαλεία

1. **Διαχείριση Κτιριακού Μοντέλου ΚΕΝΑΚ (XmlExportTab)**
   - Πλήρης υποστήριξη γενικών στοιχείων, θερμικών ζωνών, αδιαφανών & διαφανών δομικών στοιχείων, συστημάτων θέρμανσης/ψύξης/ΖΝΧ/ΑΠΕ.
   - Ταχείες προτεινόμενες τιμές ΤΟΤΕΕ (20701-1) ανά κλιματική ζώνη και περίοδο κατασκευής (Πριν το 1979, 1979-2010, Μετά το 2010, Εξοικονομώ).
   - Αυτόματος έλεγχος πληρότητας & σφαλμάτων (Audit Engine) πριν την εξαγωγή XML.

2. **Διαδραστικός Χάρτης & Εντοπισμός Κλιματικής Ζώνης (PropertyMapModal)**
   - Οπτική επιλογή τοποθεσίας στο χάρτη Google Maps με πινέζα.
   - Αυτόματος εντοπισμός διεύθυνσης, Δήμου, Νομού, Τ.Κ. και προτεινόμενης Κλιματικής Ζώνης (Α, Β, Γ, Δ) & Κλιματικού Σταθμού.
   - Υποστήριξη fallback σε OpenStreetMap / Nominatim API σε περίπτωση απουσίας API key.

3. **Ψηφιακός AI Σύμβουλος ΚΕΝΑΚ (AiConsultantModal)**
   - Ενσωματωμένος βοηθός Gemini 2.5 Flash εκπαιδευμένος στον ΚΕΝΑΚ, τις ΤΟΤΕΕ (20701-1..5) και συχνές παραδοχές μηχανικών.
   - Απαντήσεις σε πραγματικό χρόνο για τυπικές τιμές U, g, η_g, COP, EER, συντελεστές σκίασης και ειδικές περιπτώσεις.

4. **Υπολογιστές U-Value & Θερμογεφυρών (CalculatorsTab)**
   - Υπολογισμός θερμοπερατότητας $U$ πολυστρωματικών δομικών στοιχείων.
   - Αυτόματη σύγκριση με τα μέγιστα επιτρεπόμενα όρια ΚΕΝΑΚ ανά Κλιματική Ζώνη (Α-Δ).

5. **Αξιολογητής Προγράμματος "Εξοικονομώ" (ExoikonomoEvaluator)**
   - Εκτίμηση ενεργειακής αναβάθμισης (ενεργειακή κλάση κτιρίου αναφοράς & υφιστάμενου).
   - Υπολογισμός ποσοστού εξοικονόμησης πρωτογενούς ενέργειας (%) και προϋπολογισμού παρεμβάσεων.

6. **Google Drive Sync (GoogleDriveSync)**
   - Σύνδεση με λογαριασμό Google και απευθείας αποθήκευση/ανάκτηση αρχείων XML ΠΕΑ στο Google Drive.

7. **Ενσωμάτωση AutoCAD / DXF (AutocadIntegrationTab)**
   - Εισαγωγή αρχείων DXF και αυτόματος υπολογισμός εμβαδών, περιμέτρων & μηκών εξωτερικών τοίχων.
   - Γεννήτρια κώδικα LISP για αυτόματη εξαγωγή γεωμετρίας από το AutoCAD.

---

## 🛠️ Τεχνολογικό Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, `@vis.gl/react-google-maps`
- **Backend:** Node.js, Express, ESbuild (`server.ts`)
- **AI Integration:** `@google/genai` (Gemini API)
- **Cloud Services:** Firebase Auth, Google Drive API v3

---

## ⚙️ Ρύθμιση Μεταβλητών Περιβάλλοντος (.env)

Δημιουργήστε ένα αρχείο `.env` στη ρίζα του project (βασισμένο στο `.env.example`):

```env
# Gemini API Key (Server-side)
GEMINI_API_KEY=your_gemini_api_key_here

# Google Maps API Key (Client-side)
VITE_GOOGLE_MAPS_PLATFORM_KEY=your_google_maps_api_key_here
```

## 📦 Εγκατάσταση & Εκτέλεση

### 1. Εγκατάσταση εξαρτήσεων
```bash
npm install
```

### 2. Εκτέλεση σε Development Mode
```bash
npm run dev
```
Η εφαρμογή θα εκτελεστεί στη διεύθυνση `http://localhost:3000`.

### 3. Production Build & Start
```bash
npm run build
npm start
```

---

## 🔒 Ασφάλεια & Διαπιστευτήρια
- Όλα τα API keys διατηρούνται σε μεταβλητές περιβάλλοντος (`.env`) και δεν πρέπει να δεσμεύονται στο σύστημα ελέγχου εκδόσεων (Git).
- Οι κλήσεις προς το Gemini API εκτελούνται αποκλειστικά server-side (`/api/ai-assistant`) για την προστασία του `GEMINI_API_KEY`.
